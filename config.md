# Reforge configuration

- **accent** — hex color used for buttons, the progress bar, and accents.
  Example: `"#6c8cff"`.
- **show_heatmap** — show the review-activity heatmap on the deck list.
- **show_progress** — show the progress bar while reviewing.
- **heatmap_weeks** — how many weeks of history the heatmap shows
  (`53` ≈ one year).

Changes take effect the next time the relevant screen is drawn (return to the
deck list / start a review). Some changes may need an Anki restart.
